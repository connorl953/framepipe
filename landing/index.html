Why this exists

Video editing remains fundamentally unchanged since the GUI era. Humans manually scrub timelines, tweak keyframes, and export presets. But AI agents don't have hands. They don't see pixels. They think in code.

Agentic Video Editor treats your LLM as the customer. Not the human. Install once, configure via JSON, then let your agent make creative decisions: trim scenes, overlay text, detect silence, export optimized feeds — all through structured MCP tools designed for machine consumption.

This is video editing for the AI age.

18 tools for every editing task

📊

inspect_video

Understand any video through structured metadata. Resolution, duration, codec, framerate, audio tracks—everything your agent needs to make informed decisions.

✂️

trim

Cut to any time range with HH:MM:SS or seconds notation. Precise, deterministic, repeatable. Extract scenes, remove intros, create highlights.

📝

add_text

Overlay text at precise positions and time ranges. Position by pixel coordinates, set duration, choose fonts. Build captions, titles, watermarks programmatically.

💾

export_video

One-command export with YouTube, Instagram, TikTok presets. Automatic aspect ratio conversion, bitrate optimization, codec selection. No manual format juggling.

🔇

detect_silence

Find natural cut points automatically. AI-powered silence detection surfaces where to cut without manual listening. Perfect for podcast editing, interview cleanup.

How it works

1

Install

Add via npm. Supports local files and cloud storage (S3, GCS). Zero dependencies beyond Node.js.

2

Configure MCP

Define the server in your Claude Desktop config or MCP client. Point to your video library. Set API keys if using cloud.

3

Your agent edits

Claude or any LLM calls tools natively. "Trim this to 30 seconds," "add captions," "export for TikTok." Your agent handles the rest.

{
  "mcpServers": {
    "agentic-video-editor": {
      "command": "npx",
      "args": ["agentic-video-editor"],
      "env": {
        "VIDEO_PATH": "/path/to/videos",
        "EXPORT_PATH": "/path/to/exports"
      }
    }
  }
}
